# road-scene-detection

> 2026 睿抗机器人开发者大赛（RAICOM）广东赛区「AI 视觉应用」**一等奖**作品（证书编号 IITCHJRAIC26004884）。
> 面向道路场景目标检测的**模型鲁棒性优化**：在不改动网络结构、不增加任何参数的前提下，
> 通过数据侧增强与训练策略提升模型在退化条件（模糊/噪声）下的稳定性。

**数据集**：ROD（公开道路场景数据集），25 类，Train 19,186 / Val 3,511，输入 640×640
**基线模型**：yolo26s.pt（CAEv2 Backbone） ｜ **训练**：196 epochs，约 11.8 小时（RTX 单卡）
**分工**：2 人队，本人负责**数据准备、模型训练与鲁棒性评估**

完整训练日志与评估报告：[docs/YOLO26s_Aug+_Report.md](docs/YOLO26s_Aug+_Report.md)

---

## 一、方案：YOLO26s-Aug+（零结构改动）

| 手段 | 配置 |
|---|---|
| EMA 权重平滑 | decay = 0.9999，`on_train_batch_end` 回调，推理用 `best_ema.pt` |
| Downscale 在线增强 | 随机缩小至 45–80% 模拟小目标，概率 40% → 0% 三阶段退火（0-80 学习 / 80-120 退火 / 120+ 冲刺） |
| — bbox 映射校验 | 坐标同步缩放，zero-error 校验 max_err < 1e-8 |
| Blur / Noise | 各 30% 在线增强（kernel∈{3,5,7} / std=0.02×rand） |
| 尾类过采样 | 5 个尾类（Fire Hydrant 等）3× 过采样，19,186 → 23,611（+23.1%） |
| Mixup / RandAugment / Erasing | 0.15 / 启用 / 0.4 |
| 训练长度 | 196 epochs（cos_lr，seed=42，early stop 30 未触发） |

**核心思路**：不改变网络结构、零额外参数、推理速度不受影响——这正是一年后把它部署到
K210 KPU 时的前提（自定义模块会带来算子不支持的量化风险）。

## 二、精度结果（5 模型消融）

| 模型 | Epochs | Best mAP50 | Best mAP50-95 | 训练数据量 | 网络参数 |
|------|:---:|:---:|:---:|:---:|:---:|
| CA + WIoU | 80 | 0.9227 | 0.7662 | 19,186 | +CoordAtt |
| CA + EMA | 80 | 0.9256 | **0.7729** | 19,186 | +CoordAtt |
| CA + EMA + WIoU | 80 | **0.9264** | 0.7697 | 19,186 | +CoordAtt |
| YOLO26s-Aug | 80 | 0.9231 | 0.7609 | 19,186 | 原版 |
| **Aug+（本方案）** | **196** | 0.9189 | 0.7631 | **23,611** | **原版（零额外）** |

Aug+ 的 Clean 精度不是最高——赢在鲁棒性，见下节。

## 三、鲁棒性评估（核心创新点）

对验证集 3,511 张施加 10 种 corruption（旋转/缩小/翻转/模糊/噪声），比较 5 个模型的退化幅度：

| 排名 | 模型 | Clean mAP50-95 | 10 种 Corruption 均值 | 退化幅度 ↓ |
|:----:|------|:---:|:---:|:---:|
| **1** | **Aug+（本方案）** | 0.7625 | 0.3517 | **-0.4108（最优）** |
| 2 | CA + EMA + WIoU | 0.7695 | 0.3342 | -0.4353 |
| 3 | CA + WIoU | 0.7661 | 0.3276 | -0.4385 |
| 4 | YOLO26s-Aug | 0.7606 | 0.3194 | -0.4412 |
| 5 | CA + EMA | 0.7724 | 0.3296 | -0.4427（最差） |

单项里最能说明问题的两条：

| Corruption | mAP50-95 | vs Clean 退化 |
|---|:---:|:---:|
| Blur k3 | 0.7470 | **-0.0155**（几乎无退化） |
| Noise σ=15 | 0.7329 | **-0.0296**（几乎无退化） |

Blur + Noise 在线增强直接转化成了对模糊/噪声的不敏感。极端旋转（90°/270°）和 50% 缩小仍会大幅退化，是已知短板（报告末节有分析）。

## 四、复现说明

- 训练框架：Ultralytics YOLO（yolo26s.pt 为源权重）
- 关键超参：batch 16 / imgsz 640 / AdamW / cos_lr / lr0 0.01 / warmup 3 / AMP / seed 42
- 自定义增强（EMA、Downscale 调度、Blur、Noise）通过 `augmentations.py` 的训练回调注入
- 推理请使用 `best_ema.pt`（EMA 平滑，精度高于标准 `best.pt`）

> 训练脚本、自定义增强模块与权重文件体积较大，暂未开源；如需交流可联系作者。
